# Clinisight — Clinical Adverse Drug Event Predictor

Prototype clinical decision support tool that predicts a patient's risk of
multiple adverse drug events (AKI, hyperkalemia, QT prolongation, liver
toxicity, bleeding risk, hypoglycemia) using a custom PyTorch neural network
trained on synthetic, medically-plausible patient data.

Not clinically validated. For demonstration purposes only.

See `backend/` (FastAPI + PyTorch) and `frontend/` (Next.js + TypeScript).
